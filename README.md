# ML Demos

A multi-tab Streamlit app showcasing supervised learning concepts through interactive demos.

## Tabs
- Tab 1: Heart Disease Risk Predictor (Logistic Regression)
- Tab 2: Student Performance Predictor (Coming soon)
- Tab 3: Bank Marketing Predictor (Coming soon)

## Stack
Python, scikit-learn, Streamlit

## Data Sources
- Heart Disease: UCI Cleveland Heart Disease Dataset (CC BY 4.0) — Janosi, Steinbrunn, Pfisterer, Detrano
- Student Performance: UCI Student Performance Dataset (CC BY 4.0) — Cortez & Silva
- Bank Marketing: UCI Bank Marketing Dataset (CC BY 4.0) — Moro, Cortez & Rita

## Run locally
```
pip install -r requirements.txt
streamlit run app.py
```
